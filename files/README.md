C# File Handling System

Project Description

This is a simple C# Windows Forms application that demonstrates file handling in C#.
The application allows users to write text to a file, read text from a file, display all lines, delete a file, and delete an item from the list.

Features

• Write line: Writes a line of text to a file.
• Read line: Reads a line of text from a file.
• Read all line: Reads and displays all lines stored in the file.
• Delete file: Deletes the selected file.
• Delete item: Removes a selected item from the list.

Technologies Used

• C#
• Windows Forms
• .NET
• File handling (System.IO)

How to Run

1. Open the project in Visual Studio.
2. Build the project.
3. Press Start or F5 to run the application.
4. Use the buttons to test the file-handling features.

How to Test

1. Enter some text in the appropriate input field, if available.
2. Click Write line to save a line.
3. Click Read line to read a line from the file.
4. Click Read all line to display all saved lines.
5. Click Delete item to remove a selected list item.
6. Click Delete file to remove the file.

Notes

• Make sure the file path used in the code is valid.
• The application may need to create the file before reading or deleting it.
• Deleting a file permanently removes it, so test with sample data.
